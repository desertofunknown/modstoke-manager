# Modstoke branding

Modstoke is a family of independent modding tools published by OpenACAI, a nonprofit. Use the credit **by OpenACAI** with the product name.

| Product | Name |
| --- | --- |
| Desktop manager | Modstoke Manager |
| Game loader | Modstoke Loader |
| Admin mod | Modstoke Admin |
| Development kit | Modstoke SDK |
| Website and mod catalog | Modstoke |

The website is **modstoke.com**. The Manager reads the community server list and the loader release feed from it. The website and mod catalog are separate work, and the Manager's mod catalog addresses are unchanged.

The manager supports **Sons of the Forest**. It is not affiliated with or endorsed by Endnight Games. Keep the game name in compatibility descriptions and retain the notices for upstream software. Don't bundle the game's art: the Sons of the Forest skin reads it from the player's installation.

## Product artwork

`public/modstoke-mark.svg` is the source for the manager's amber M and ember mark. Application and installer icons are generated from it with `tauri icon`. `docs/assets/modstoke-banner.svg` is the source for the Nexus page banner, and `docs/assets/modstoke-banner.png` is the export uploaded there.

Display names do not determine installed identities. See [rename compatibility](BRAND_COMPATIBILITY.md) before changing package names, paths or integration IDs.
